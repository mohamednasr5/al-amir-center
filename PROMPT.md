## 🔍 SEO REQUIREMENTS (100% Optimization Target)

### On-Page SEO
1. **Meta Tags:**
   - Title tag (unique per page, max 60 chars)
   - Meta description (unique per page, max 160 chars, includes keywords)
   - Meta keywords (relevant keywords in Arabic and English)
   - Viewport meta tag
   - Charset UTF-8
   - Language attribute (lang="ar", dir="rtl")
   - Robots (index, follow)
   - Googlebot meta
   - Revisit-after
   - Author credit
   - Generator credit

2. **Open Graph Tags (Facebook/Social Sharing):**
   - og:type, og:url, og:title, og:description
   - og:image (1200x630 recommended)
   - og:image:width, og:image:height
   - og:locale (ar_EG)
   - og:site_name

3. **Twitter Card Tags:**
   - twitter:card (summary_large_image)
   - twitter:url, twitter:title, twitter:description
   - twitter:image

4. **Canonical URLs** on every page

5. **Structured Data (JSON-LD):**
   - @type: LocalBusiness (main entity)
     - name, url, logo, image(s)
     - telephone, email
     - address (PostalAddress with streetAddress, addressLocality, addressRegion, addressCountry)
     - geo coordinates (latitude, longitude)
     - openingHoursSpecification
     - areaServed (multiple cities)
     - hasOfferCatalog
     - sameAs (social profiles)
   - @type: FAQPage (for Q&A content)
   - @type: Service (for services offered)
   - @type: Review (for testimonials)
   - @type: Person (for manager)
   - @type: WebPage (on inner pages)

6. **Geographic Meta Tags:**
   - geo.region, geo.placename
   - geo.position, ICBM

7. **Semantic HTML5:**
   - Proper heading hierarchy (h1 > h2 > h3)
   - Semantic elements (header, nav, main, section, article, aside, footer)
   - ARIA labels and roles
   - Alt text for all images
   - Skip navigation link for accessibility
   - lang and dir attributes

### Technical SEO
1. **robots.txt** - Allow all crawlers, point to sitemap
2. **sitemap.xml** - XML sitemap with all pages and images
3. **Clean URLs** - No query parameters, descriptive filenames
4. **Fast Loading:**
   - Minified CSS/JS (in production)
   - Optimized images (WebP format if possible)
   - Lazy loading for images (loading="lazy")
   - Preconnect to external resources
   - Defer non-critical JavaScript
5. **Mobile-Friendly** - Responsive design
6. **HTTPS ready** (SSL certificate needed for domain)

### sw.js (Service Worker) Features
1. **Cache Strategy:**
   - Cache-first for static assets
   - Network-first for navigation requests
   - Stale-while-revalidate for API calls (if any)
   - Fallback to offline page when offline
2. **Offline Support:**
   - Cached HTML pages accessible offline
   - Offline fallback page or cached homepage
3. **Background Sync:**
   - Queue failed form submissions
   - Sync when back online
4. **Push Notifications:**
   - Ready for push notification integration
   - Notification click handling
5. **Install Prompt:**
   - Custom install button (NOT just "Add to Home Screen")
   - beforeinstallprompt event handled
   - Display install button naturally after user interaction

### Install Banner Behavior
